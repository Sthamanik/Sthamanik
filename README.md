## 🚀 Projects

### [FinVault](https://github.com/Sthamanik/FinVault) — Financial Investment Platform Backend
Production-ready REST API backend built for investment and wealth management platforms.  
**Stack:** TypeScript · Node.js · Express · MongoDB · Redis · BullMQ · Docker · GitHub Actions
- Version-based cache invalidation, no wildcard SCAN patterns, stale keys expire via TTL
- Four-tier rate limiting with per-context reasoning, authenticated routes keyed by user ID not IP
- JWT refresh token rotation with stolen token detection
- Graceful Redis degradation, cache failures fall through to MongoDB silently
- Async file deletion via BullMQ with exponential backoff retry
- Full CI/CD, tests gate Docker image build and push to registry
